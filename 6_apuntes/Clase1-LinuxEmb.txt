$ pwm te dice donde estas

$ cd cambiar directorio
$ rm borrar (-r recursivo, -f force, sin preguntar)
$ sudo Correr como root (admin)

abrimos el Makefile (automatizador de compilacion)
$ nano Makefile

KDIR: Directorio del modulo de kernel
$(shell uname -r) concatena la version del kernel

MDIR: donde van los archivos que se generan al compilar

### hello_kernel01.c ###

EVENTOS:    Cuando se carga el modulo en el kernel se corre hello_kernel_init()
            Cuando se saca el modulo del kernel se corre hello_kernel_exit()

COMPILAR
$ make # da la orden a make para que compile
$ cd build # entro a carpeta /build
$ sudo insmod build/hello_kernel.ko # carga modulo en el KERNEL
ko es "kernel object"

Donde imprime el kernel? Con el programa dmesg
$ dmesg

IMPORTANTE: A medida que inicializamos un modulo, imprimir mensajes de kernel (NO HAY DEBUG)
Poner el nombre del 

$ lsmod # muestra todos los modulos cargados en el kernel
$ sudo rmmod <modulo> # saca modulo del kernel

$ dmesg | grep utn-fra-td3 # grep filtra texto, | es una OR logica para programas

BLINK LED

Como hago para hacer parpadear un led?
Abrimos un nuevo hilo con kthread_run() - Devuelvo un handle (thread1) al hilo creado
Verificar que el handle es valido, sino return un -1 --- asi el kernel no carga el modulo y tira mensajes de error
-- Cargar un modulo en el kernel implica inicializar recursos del sistema

Creo un nuevo hilo (thread2) y SI NO LO PUEDO CREAR libero los recursos del anterior (thread1)

$ dmesg -wT # Corre continuamente los mensajes de kernel (con timestamp formateado)
